# evaluacion 2: busqueda de raices y analisis de convergencia

este repositorio contiene la implementacion y comparacion de seis metodos numericos para la busqueda de raices sobre seis funciones representativas.

## entorno y ejecucion

crear un entorno virtual con python 3.10+ e instalar dependencias:

python -m venv venv
source venv/bin/activate  # en windows: venv\Scripts\activate
pip install -r requirements.txt
